# DriftSense — Binding Feature Contract Specification

This document defines the formal contract for every input feature generated by `FeaturePipeline` (`src/driftsense/features/`). It specifies feature definitions, window boundaries, inclusion semantics, and cryptographic leakage mitigations in accordance with **Part G (Global Preamble, G6)** and **Phase 5** requirements.

---

### Core Anti-Leakage Invariants

1. **Prediction-Time Left-Closed Semantics (Contract 8):**
   For any forecast generated for interval $[t, t+1)$, all endogenous target lags, rolling summaries, and usage metrics are computed strictly over past observations $< t$.
2. **Shifted Rolling Window Rule:**
   All rolling aggregations are computed on `series.shift(1)` across historical time steps. The current row at time $t$ is strictly excluded from its own rolling feature window.
3. **Event Timing Rule:**
   An operational event starting at timestamp $T$ never influences any feature for rows with timestamp $< T$. Future events ($> t$) are strictly filtered before feature computation.
4. **Label Isolation Rule:**
   The ground-truth anomaly label table (`anomaly_labels`) is quarantined. Columns such as `label_id`, `primary_cause`, `contributing_causes`, and `severity_score` are strictly forbidden from entering any feature matrix.
5. **Fit-on-Train Scaler Rule:**
   All normalization, feature scaling, and categorical encoders are `.fit()` strictly on the training partition ($D_{\text{train}}$) and `.transform()` on subsequent validation/test partitions.

### Mandatory Anti-Leakage Verification Suite

Every feature listed above must pass the automated verification suite implemented in `tests/test_leakage.py`:
1. **Perturbation Test:** Modifying data after time $T$ produces bit-identical feature vectors for rows $\le T$.
2. **Fit-on-Train Test:** Scalers expose normalization statistics identical to those computed on $D_{\text{train}}$ only.
3. **Label Isolation Test:** Confirms ground-truth anomaly label columns never enter the feature matrix.
4. **Event Timing Test:** An event starting at $T$ never alters features at timestamp $< T$.
5. **Chronological Split Test:** $D_{\text{train}} < D_{\text{val}} < D_{\text{test}}$ strictly in time with empty index intersections.
