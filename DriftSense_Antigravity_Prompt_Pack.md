All cells must be safe to rerun. Each notebook header states: runtime type, estimated runtime, RAM, disk, expected outputs.

## G6. Mandatory leakage and validation rules

- Split chronologically BEFORE fitting any transform, encoder, scaler, or learned feature.
- Fit all transforms on training data only.
- Rolling-window features exclude the current row unless the current row is explicitly the prediction target. Define the window in code and in a docstring.
- Event features respect event start time and detection availability. No post-anomaly measurements.
- Labels (known cause, anomaly flags) live in a separate label table and are never model inputs.
- Tune thresholds and select models on validation only. Test set is touched once, in the final evaluation phase.
- Real-data and synthetic-data results are reported separately and labelled.
- Correlation, importance, and SHAP are never described as causal proof.
